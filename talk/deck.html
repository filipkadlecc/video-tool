How it works · 1

Then I met Remotion.

  • AskYour scene asks one question: what frame are we on?
  • AnswerYou return what frame 47 looks like. That's the whole API.
  • ExportHeadless Chrome screenshots every frame. ffmpeg stitches them.

No Figma export. No layers. A video is a text file — and models are exceptionally good at writing React.

// what the AI hands back — the whole file
export const durationInFrames = 225;

export default function Scene() {
  // "what frame are we on?" → 47
  const frame = useCurrentFrame();

  const rise = spring({
    frame: frame - 12, fps,
    config: SNAPPY,
  });

  // "here's what frame 47 looks like"
  return (
    <Headline
      opacity={rise}
      y={(1 - rise) * 40}
    >Everything runs on Apify</Headline>
  );
}
How it works · 2

Great engine. Terrible taste.

  • The problemRemotion could animate anything — and the style was all over the place. So I taught it our house style.
  • TokensOur palette, ported out of the design system. Every scene imports it; a raw hex code is a rule violation.
  • Components29 scenes from our real marketing. It opens the actual source file before it copies one.
  • ReferencesReal frames from real Apify videos, as images. It sees the house style instead of reading the word "clean".
  • LimitsThe banned moves are a seven-value enum. No entrance blur, no fade from black, no slide-wipe — not forbidden, unsayable.
How it works · 3

Then I put it all in one place.

  • PromptDescribe a scene. It animates it.
  • TemplatesOr drop in a branded block that's already made.
  • EditGive it footage — it cuts the dead air on its own.
  • ComposeOr it builds the finished video, footage and animation together.
  • SVGHand it a logo or a diagram and it animates the file itself.

It turned out far more powerful than I thought it would be.

If you want to build one

Three things I'd tell you.

  • OneBuild for the job you already do. I've edited video for years, so I know when it looks wrong. A tool for a job you don't do is a demo.
  • TwoLet it see its own output. Frames beat prompt-engineering. For you it might be screenshots, tests, a diff.
  • ThreeKill what doesn't earn its place. A second engine cost me three months and produced two videos. One was a test. Deleted.
